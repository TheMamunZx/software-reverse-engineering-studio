# Module: Design Quality Critic

## Purpose
Critically inspect an implemented interface and turn visible defects into prioritized, actionable fixes.

## Review dimensions
- Visual hierarchy, typography, alignment, spacing, consistency, and density.
- Brand distinctiveness and fit to the product's domain.
- Navigation clarity and completion of key user tasks.
- Responsive behavior at representative viewport sizes.
- Accessibility: semantics, focus order, keyboard operation, contrast, labels, and reduced motion.
- Interaction states: hover, focus, pressed, loading, empty, error, success, disabled, and permission denied.
- Content quality: realistic wording, accurate labels, no invented proof points or fake social proof.

## Workflow
1. Inspect the actual implementation and run it where possible.
2. Capture or inspect representative pages/states at target viewports.
3. Record each issue with evidence, severity, user impact, and affected component.
4. Separate objective defects from subjective preferences.
5. Fix high-severity and high-impact issues first.
6. Re-run visual and functional checks; report remaining issues.

## Outputs
Prioritized design audit, annotated issue list, remediation plan, and before/after verification notes.
