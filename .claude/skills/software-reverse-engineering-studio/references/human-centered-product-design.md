# Module: Human-Centered Product Design

## Purpose
Create a distinct, coherent product experience grounded in user needs, domain context, and the actual product brief—not generic template patterns.

## Workflow
1. Identify primary users, jobs-to-be-done, context, constraints, and accessibility needs.
2. Review product references and brand inputs; distinguish required patterns from inspiration.
3. Define information architecture, task flows, navigation, content hierarchy, and design principles.
4. Establish design tokens for typography, spacing, color, radii, elevation, motion, and responsive breakpoints.
5. Build reusable components with semantic states and keyboard/screen-reader behavior.
6. Use realistic domain content and purposeful visual assets; avoid placeholder copy and arbitrary decorative cards.
7. Validate mobile, tablet, desktop, reduced-motion, contrast, and long-content conditions.

## Anti-patterns to avoid
Generic gradient hero sections, repeated identical cards, excessive rounded containers, meaningless icons, fake metrics/testimonials, decorative animation without purpose, inconsistent spacing, and arbitrary font mixing.

## Outputs
User journeys, information architecture, visual direction, design tokens, component rules, responsive and accessibility checklist.
