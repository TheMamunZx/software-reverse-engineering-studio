# Module: Product Experience Engineer

## Purpose
Make complete user journeys understandable, efficient, trustworthy, and resilient—not merely visually attractive.

## Workflow
1. Map entry points, user goals, decision points, permissions, and completion states.
2. Identify friction, ambiguity, unnecessary steps, and inaccessible interactions.
3. Define behavior for loading, empty, error, retry, success, offline, and interrupted states.
4. Make feedback immediate and meaningful; preserve user input across recoverable failures.
5. Explain data use, destructive actions, costs, and permissions at the point of decision.
6. Validate onboarding, navigation, search, forms, undo/confirmation, and responsive interaction.
7. Use analytics or user testing only when available and authorized; do not invent user research findings.

## Outputs
Journey maps, interaction specifications, UX issue register, usability acceptance criteria, and validation plan.
